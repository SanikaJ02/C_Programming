## Requirements

- A C compiler, such as GCC.
- A code editor or IDE, such as Visual Studio Code.

## How to Compile and Run

1. Open a terminal in the directory containing the C program.
2. Compile the program using GCC:

   ```bash
   gcc program1_1.c -o program1_1
   ```

3. Run the executable on Windows:

   ```bash
   program1_1.exe
   ```

   On Linux or macOS:

   ```bash
   ./program1_1
   ```
